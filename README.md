# Veraspect marketing assets

Public host for brand files that must be reachable by URL, such as the email signature logo. Served by GitHub Pages from `main`.

| File | Use | URL |
|---|---|---|
| `veraspect-logo-email.png` | Horizontal lockup, Primary Navy on white, 360 x 105, for the email signature (rendered at 180 x 53) | https://gmadden99.github.io/veraspect-marketing-assets/veraspect-logo-email.png |

`make_logo.py` rebuilds the logo from the locked white lockup in the private marketing repo: `python3 make_logo.py <Veraspect_Logo_White_1400.png> veraspect-logo-email.png`.

Source of record for every brand file is the private `veraspect-marketing` repo (`brand/`). Nothing here is edited by hand.
